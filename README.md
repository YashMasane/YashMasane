I build AI systems that **reason, act, and hold up in production** — not just in notebooks. My work sits at the intersection of **Agentic AI, RAG pipelines, and LLM-powered applications**, with a strong foundation in mathematics and scientific computing.

Currently at **Cogninest AI**, I'm building:
- 🧠 **NL2SQL pipelines** with LLM + semantic layers — ~70% latency reduction, ~60% cost savings
- 📚 **RAG knowledge bases** with 5-stage indexing & async workers — ~90% faster user experience
- 🤖 **Agentic systems** using LangGraph ReAct agents with 15+ MCP tool integrations
- 🔐 **Production infrastructure** — JWT-based RBAC, database-per-tenant isolation, encrypted credential storage
